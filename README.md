Projekt ma na celu stworzenie wygodnego interfejsu do podłączania rejestratorów kamer i przeglądania nagrań niezależnie od wykorzystywanego systemu operacyjnego. 

Serwer bazuje na języku Python, wersja 3.11

Plik index.html stanowi interfejs aplikacji.

Całość przygotowana pod docker, dzięki czemu aplikacja działa niezależnie od posiadanego systemu operacyjnego. Wszystkie dane zapisywane są w bazie SQLite
